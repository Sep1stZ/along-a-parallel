# Parallel Sans SC

Self-hosted subset derived from the official Google Fonts Noto Sans SC variable font (version 2.004-H2).

- File: `noto-sans-sc-latin-cjk.woff2`
- Internal family: `Parallel Sans SC`
- Style: normal
- Variable weight range: 400–700
- Size: 793,528 bytes; 3,278 Unicode mappings
- License: SIL Open Font License 1.1; see `OFL-NotoSansSC.txt`
- Credit: Adobe and Noto project contributors. Subset prepared by Along a Parallel.

Copyright and OFL name records are preserved. The V2 subset covers Chinese text in the complete local catalog and current editorial/UI copy. Other scripts use system fallbacks. Rebuild with `scripts/build-font-subset.py` after content changes, then run `scripts/refresh-assets.ts` to refresh asset hashes. Full metadata is in `subset-info.json`; source and license URLs are in `assets-manifest.json`.
