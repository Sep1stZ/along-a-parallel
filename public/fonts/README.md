# Parallel Sans SC

Self-hosted subset derived from the official Google Fonts Noto Sans SC variable font (version 2.004-H2).

- File: `noto-sans-sc-latin-cjk.woff2`
- Internal family: `Parallel Sans SC`
- Style: normal
- Variable weight range: 400–700
- Size: 357,056 bytes; 1,749 Unicode mappings
- License: SIL Open Font License 1.1; see `OFL-NotoSansSC.txt`
- Credit: Adobe and Noto project contributors. Subset prepared by Along a Parallel.

Copyright and OFL name records are preserved. Arabic, Tibetan, arbitrary user-entered names and newly added Chinese copy may require system fallback. Full metadata, source hashes and covered range notes are in `subset-info.json`; source and license URLs are in the project `assets-manifest.json`.
