# V2内容编辑与审校记录

审阅日期：2026-11-11。新增44城与旧16城合计60城；新增176条中文主题手记，四主题分别为自然地理、城市建筑、公共生活、饮食。新增44张SVG为项目原创主题示意，非实景照片与精确建筑复原。

## 来源与编辑口径

- 新44城各有实际读取的GeoNames离线记录与至少一项实际读取的人文资料，地名稳定ID、国家代码、坐标及IANA时区已逐行核对。同名地点按国家与区域确认；参考点不是城市边界。
- 每篇主题手记50至100汉字。`verified`只覆盖来源scope明确列出的事实，不代表整篇网页或所有故事细节、实时运营都已经核验；旧价格、开放时间、班次与广泛居民习惯没有作为实时数据。
- 部分官方网页与百科请求曾403、超时或返回无正文页面；改用真正可读的材料后重写对应内容。未取得正文的资料没有被标为verified。正文不收录第三方文章长篇原文。
- 国家饮食背景与城市个体案例分别处理，不把一种食物称为全城共同习惯。喀土穆的旧城市指南仅作为历史空间与餐饮线索，不推断战时营业和通行。
- GeoNames数据按CC BY 4.0署名，坐标/国家/时区来源为2026-11-11离线快照。主题文字与SVG由项目原创编写，第三方图片未被批量引入。
