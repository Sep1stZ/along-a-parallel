## 产品与部署边界

- 内容为 16 座城市的静态策展条目，来源范围与状态见 `SOURCES.md`；插画为原创示意。
- 匿名旅程绑定浏览器 Cookie，没有账户登录或跨设备私密同步。
- 中文和拉丁文字使用本地字体；阿拉伯文、藏文等原名使用系统字体回退。
- SQLite 需要可写的持久磁盘，当前运行方式面向单实例 Node 服务。
- GitHub 开源仓库发布与公网网站托管分别验证。
