# 城市速读与地理档案的内容边界

此轮增加可阅读内容，不增加城市目录数量，也不把基础地理推导伪装成地方历史或居民生活。

## 每个地点的地理档案

全部34,214个既有地点按需提供：可读国家/地区和一级行政区、近似中心坐标、南北半球与几何纬度分区、IANA时区说明、点位海拔（有值才解释）、原名与别名、3个附近收录地点、3个距离较近的既有精选阅读入口。

一级行政区来自已固定哈希的GeoNames `admin1CodesASCII.txt` 和 `alternateNamesV2.zip`：2,764个已用行政区中，1,934个有带语言标签的中文名称，其余保留上游可读名称。地理数据及其中文名称仍按 **CC BY 4.0** 提供。

附近地点采用WGS84经纬度、平均地球半径6371.0088千米的大圆距离；方向为起始方位角的八方位近似。距离表示点位间球面直线距离，不表示道路里程、城市边界相隔距离或现实出行可达性。三维球面KD树处理跨180°经线与极区，索引只保存紧凑坐标和次序，不缓存三万份完整详情。地理分区使用约23.44°回归线和66.56°极圈，不据此推定实际气候、食物、习俗或生活方式。

## 有来源的中文城市简介

本批**165篇、330段**城市速读已经审读并发表，其中中国及港臺63篇，其他地区102篇。220个明确匹配到既有GeoNames ID的下载目标中，182篇取得可读中文导言，38篇未成功取得；在可读候选中，15篇未入选，另有2篇因消歧义或国家条目错配排除。数量按实际可读且进入白名单的地点计算，不把下载目标或HTTP成功数当作发表数。

实际中文导言来自Wikimedia官方Core API：

`https://api.wikimedia.org/core/v1/wikipedia/zh/page/{title}/with_html`

每篇保留实际读取的修订编号、完整oldid链接、原始响应SHA-256、读取日期、来源标题、贡献者署名、许可链接和具体摘编范围。内容为原导言节选或忠实中文整理；编辑时删去大量过时人口/GDP、即时榜单、营销称号和不支持的泛化。百科文章及其改编采用 **CC BY-SA 4.0**，不改成MIT。原文作者通过每篇原始修订页面及其历史记录署名；本项目的删节、改写和整理继续按相同许可提供。

城市速读与60城既有四主题精选手记分开：它不会填充 `stories`、不会改变 `level` 或 `hasStory`，也不意味着逐项独立复核了百科的全部引文。API与阅读界面明确保留来源和许可。

## 可复现导入与发布白名单

需要Node.js 24和Python 3标准库，无新增第三方软件包。运行中的网站不访问外部数据源，也不需要Python。

```powershell
# 从已固定的GeoNames缓存生成行政区中文名。
python scripts/import-region-labels.py

# 只下载候选，不会发布或覆盖审读白名单。
node scripts/import-city-articles.mjs --download

# 已有缓存时安全重抽导言，完全离线。
node scripts/import-city-articles.mjs --offline

# 只合并已审读、固定修订和SHA的条目，无网络请求。
node scripts/finalize-city-articles.mjs
```

原始下载位于忽略提交的 `.data/city-articles/2026-11-13/`，包含API JSON和安全抽取的正文候选。HTML提取使用Python标准库HTMLParser，完整跳过嵌套信息框、图片、脚注、脚本、CSS和隐藏内容；不会用正则剥标签后把模板属性当正文。第三方整篇HTML不发布。

发表白名单分别位于 `scripts/city-article-reviews-china.json`、`src/data/city-articles-china-additional.review.json`、`src/data/city-articles-international.review.json`。每篇摘编及来源范围已经逐项审读。`finalize`只能合并这些明确条目；若缓存中的源修订、标题或SHA与审读记录不同，直接报错，必须重新明确审读。清洁克隆可仅用已提交白名单重建相同发布JSON；它不会假装重新获取或重新审阅了未随仓库发布的全文。

新下载、HTTP成功、拥有百科标题都不能自动使内容进入白名单。实读发现的错配已经排除，包括美国San Diego名称取到消歧义页、巴西Salvador名称取到萨尔瓦多国家页。部分别名跳转返回HTML、部分请求404/504或失败，也不会凭城市名称自动生成替代人文信息。

详细审读范围见 [中国城市审读记录](CITY-ARTICLES-CHINA-REVIEW.md) 与 [国际城市审读记录](CITY-ARTICLES-INTERNATIONAL-REVIEW.md)。首批20篇中文整理的逐篇范围直接保存在对应白名单 `scope` 字段中。

## 验证

`tests/place-profile.test.ts` 对全部地点检查地理档案、3个真实近邻、3个有精选内容的入口及空故事边界；随机全球点、180°经线两侧和极区的KD树结果与全量暴力球面距离交叉验证。文章测试检查实际发表数量、去重、可读正文、逐篇许可、固定修订与源哈希，防止模板/CSS泄漏。
